What this packet can prove

The public files let you inspect the fixtures and recalculate completion and report-delivery counts. SHA256SUMS covers the exact target, instruction, and oracle files. The methods README records the runtime profile and comparison limits.

Raw agent transcripts and server logs remain private because they include machine paths and operational detail. This packet therefore cannot independently establish every manual correctness judgment in the article. Report delivery is observable in the ledger; finding validity requires review of the private traces.
